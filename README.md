sbox Linux Book aims to document the best known methods for playing and building the s&box game, editor, and server, both via Proton and natively.

sbox Linux Book is powered by mdBook: https://rust-lang.github.io/mdBook/

Be sure to consult the mdBook guide and/or install mdBook locally if you PR changes with more than simple text edits.

sbox Linux Book is currently set up with two preprocessors, one of which has some inline functionality for embedding things such as YouTube videos, Github Gists, and more, so feel free to consider using it in your PRs if necessary.
